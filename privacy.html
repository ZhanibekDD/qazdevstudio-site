Политика конфиденциальности

Последнее обновление: 1 декабря 2024

1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта QazDev Studio (qazdevstudio.kz).

Используя сайт, вы соглашаетесь с условиями данной политики.

2. Какие данные собираются

При заполнении формы на сайте вы можете указать:

  • Тип необходимой услуги
  • Город
  • Номер телефона
  • Комментарий к проекту

Форма на сайте формирует сообщение для отправки через WhatsApp. Данные не сохраняются на серверах сайта — они передаются напрямую в мессенджер.

3. Цель обработки данных

Данные используются исключительно для:

  • Связи с вами по вашему запросу
  • Обсуждения и реализации проекта
  • Предоставления услуг QazDev Studio

4. Передача данных третьим лицам

Ваши данные не продаются и не передаются третьим лицам в коммерческих целях.

Данные могут быть переданы только при наличии законных оснований (например, по требованию суда).

5. Файлы cookie

Сайт использует минимальное количество технических файлов cookie, необходимых для корректной работы. Аналитические и рекламные cookie не используются.

6. Ваши права

Вы вправе в любое время:

  • Запросить информацию о хранимых данных
  • Потребовать удаления ваших данных
  • Отозвать согласие на обработку данных

Для этого напишите на hello@qazdevstudio.kz.
