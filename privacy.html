Политика конфиденциальности

Последнее обновление: 21 июня 2025

1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта QazDev Studio (qazdevstudio.kz).

Используя сайт, вы соглашаетесь с условиями данной политики.

2. Какие данные собираются

2.1. Данные формы обратной связи. При заполнении формы на сайте вы можете указать:

  • Тип необходимой услуги
  • Город
  • Номер телефона
  • Комментарий к проекту

Форма формирует сообщение и открывает WhatsApp — данные передаются напрямую в мессенджер. Копия заявки (без хранения в открытом виде) сохраняется во внутреннюю базу данных сайта для учёта обращений.

2.2. Технические данные аналитики. Для улучшения работы сайта автоматически фиксируются:

  • IP-адрес посетителя (используется для определения примерного города, затем не передаётся третьим лицам)
  • Тип устройства, браузер, операционная система (из User-Agent)
  • Адрес страницы и заголовок
  • Источник перехода (реферер, UTM-метки)
  • Факты взаимодействия с сайтом: клики по кнопкам WhatsApp, Telegram, телефону, открытие разделов FAQ
  • Глубина прокрутки страницы

Данные аналитики хранятся на сервере сайта в зашифрованной SQLite-базе и не передаются рекламным сетям или системам отслеживания (Google Analytics, Meta Pixel и подобным).

3. Цель обработки данных

Данные используются исключительно для:

  • Связи с вами по вашему запросу
  • Обсуждения и реализации проекта
  • Анализа посещаемости и улучшения сайта
  • Предоставления услуг QazDev Studio

4. Передача данных третьим лицам

Ваши данные не продаются и не передаются третьим лицам в коммерческих целях.

Для определения примерного города посещения используется сервис ip-api.com — на него передаётся только IP-адрес посетителя без каких-либо персональных данных.

Данные могут быть переданы только при наличии законных оснований (например, по требованию суда).

5. Срок хранения

Данные аналитики (визиты, события) хранятся не более 90 дней, после чего автоматически удаляются. Заявки из формы обратной связи хранятся до выполнения запроса или до обращения об удалении.

6. Файлы cookie и localStorage

Сайт использует браузерный localStorage для хранения анонимного идентификатора посетителя (случайный набор символов, не содержащий персональных данных). Это позволяет отличить новые визиты от повторных без использования cookie-трекеров.

Рекламные и аналитические cookie сторонних сервисов не используются.

7. Ваши права

Вы вправе в любое время:

  • Запросить информацию о хранимых данных
  • Потребовать удаления ваших данных
  • Отозвать согласие на обработку данных

Для этого напишите на hello@qazdevstudio.kz.
