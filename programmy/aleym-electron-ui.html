Оригинальное описание разработчика

Warning: The application didn't go through prefessional security auditing. Graphical user interface for Aleym, the highly extensible news aggregation system and knowledge-base. It prioritizes security and privacy by relying on anonymized networks and randomized fetching scheudle. It balances both a real-time like experience and user privacy. Features: Local first Multi-network anonymized fetching with support for builtin isolated Tor connections Privacy-reserving fetch scheduling without identifiable patterns AI-base summarization with Ollama (installed separately) Supported standard feeds: RSS Atom Json
