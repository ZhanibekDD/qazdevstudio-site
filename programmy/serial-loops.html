Оригинальное описание разработчика

Serial Loops is a full-fledged editor for the Nintendo DS game Suzumiya Haruhi no Chokuretsu (The Series of Haruhi Suzumiya). In its current state, it allows you to edit nearly everything about the game, and more is planned for the future. Please check our documentation on our website for more information on how to use it! Fully edit the game's scripts, completely rewriting your own Haruhi visual novel with a powerful preview feature! Completely change the game's scenario, moving events around in the order you'd like them to occur! Replace the game's graphics, including backgrounds, CGs, character sprites, chibis, and more! Edit the game's soundtrack, swapping out background music and voice lines! (SFX coming in a future release!) Edit character nameplates, topics, UI text, tutorial mappings, and dialogue colors! Apply pre-written assembly hacks for even greater control of the game! Partial editing of group selections, puzzles, and chess puzzles, and viewable maps! A full save editor for editing save games as well!
