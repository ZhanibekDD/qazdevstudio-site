Оригинальное описание разработчика

OpenDeck is an application for using stream controller devices like the Elgato Stream Deck. OpenDeck supports the majority of the original Stream Deck plugins, like Elgato's own Discord plugin, unlike other softwares (e.g. streamdeck-ui, StreamController, Boatswain) which are much more limited. Please note that you will need to install udev subsystem rules for your device to be detected. For more information, see the Installation section of the project README on GitHub. Some compiled plugins are not compiled for Linux, so you may need to have Wine (and Wine Mono) installed on your system (natively, as the Wine Flatpak is not supported). Similarly, for using plugins made with Node.js, the Node.js Flatpak is not supported. From Multi Actions and Toggle Actions to switching profiles when you switch apps and brightness control, OpenDeck has all the features you'd expect from stream controller software. Consider that the power of your Stream Deck actually comes from the software you use with it, then remember how much you paid for it.
