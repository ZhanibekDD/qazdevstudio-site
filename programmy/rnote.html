О программе

Rnote предоставляет бесконечный холст, кисти, фигуры, текст и импорт документов. Подходит для конспектов, объяснений, аннотаций PDF и быстрых идей.

Возможности

  • Рукописные заметки
  • Графический планшет
  • Фигуры
  • Экспорт PDF

Как установить Rnote в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.github.flxzt.rnote
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
