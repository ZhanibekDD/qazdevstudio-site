Рабочее пространство для SSH, SFTP и нескольких удалённых терминалов.

О программе

Netcatty хранит подключения, открывает терминальные сессии и передаёт файлы по SFTP в одном окне. Полезен администраторам и разработчикам, которые регулярно работают с несколькими серверами.

Возможности

  • SSH
  • SFTP
  • Терминалы
  • Удалённые серверы
Безопасная загрузка: кнопка получает последний релиз через GitHub API. QazDev загружает оригинальный файл автора и не изменяет установщик.
