Оригинальное описание разработчика

Trayscale is an unofficial GUI interface for the Tailscale daemon particularly for use on Linux, as no official Linux GUI client exists. It provides a basic system tray icon and a fairly comprehensive UI with support for many of Tailscale's features. Trayscale interfaces with the Tailscale daemon, tailscaled , to perform many of its operations. In order for this to work, the daemon must have been configured with the current user as the "operator". To do this, run sudo tailscale set --operator=$USER from the command-line at least once manually.
