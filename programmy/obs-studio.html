О программе

OBS Studio — бесплатная программа для записи экрана и прямых трансляций. Поддерживает сцены, камеры, микрофоны, захват приложений, плагины и аппаратное кодирование.

Возможности

  • Запись видео
  • Стриминг
  • Сцены
  • Плагины
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
