О программе

Drawing предлагает карандаш, фигуры, текст, обрезку, размытие и другие базовые инструменты. Подходит для быстрых правок без запуска тяжёлого графического редактора.

Возможности

  • Рисование
  • Фигуры и текст
  • Обрезка
  • Размытие

Как установить Drawing в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.github.maoschanz.drawing
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
