Как установить dmidiplayer в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub net.sourceforge.dmidiplayer
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Multiplatform MIDI File Player for Linux, Windows and macOS with advanced features: MIDI Output to hardware MIDI ports, or any other Drumstick backend like soft-synths Transpose song tonality between -12 and +12 semitones Change MIDI volume level (using MIDI CC7) Scale song speed between half and double tempo Piano Players, MIDI Channels, Rhythm, and Lyrics (Karaoke) views Supports .MID (Standard MIDI files), .RMI (RIFF RMID), .KAR (MIDI Karaoke), and .WRK (Cakewalk) file formats
