Как установить Jasmine в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.alamahant.Jasmine
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Jasmine is a website launcher and session management platform with shared, named or private profiles for each tab. Also featuring Internet Radio, IPTV and Podcasts. Key Features: Core: Smart Bookmarking - Store websites with titles, URLs, comments, favicons, and login references Session Management - Create, save, and restore multi-tab sessions with one click Flexible Profiles - Choose between shared, named-shared (user-created), or private (incognito) profiles per tab Multi-Account Support - Access multiple accounts on the same service without conflicts Media: Internet Radio - Browse, search, and play thousands of stations with local icon caching IPTV - Import M3U playlists, browse channels by category, and watch live TV Podcast Manager - Subscribe via iTunes search or RSS, manage episodes, and play audio Utilities: Download Manager - Progress tracking and file organization Ad Blocker - Block unwanted ads and popups for cleaner browsing 2FA Integration - Built-in TOTP code generator Security: Master Password Protection - Encrypted data protection Private Profiles - Completely isolated browsing environments
