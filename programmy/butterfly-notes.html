Свободный холст для рукописных заметок, схем и рисунков на разных устройствах.

О программе

Butterfly предлагает бесконечный холст для пера, фигур, текста и изображений. Документы можно хранить локально, экспортировать и открывать на компьютере или мобильном устройстве.

Возможности

  • Бесконечный холст
  • Рисование
  • Рукописные заметки
  • Экспорт
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
