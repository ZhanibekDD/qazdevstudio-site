Что делает Git for Windows

Git for Windows устанавливает Git Bash, основные консольные инструменты и поддержку репозиториев. Подходит для работы с GitHub, GitLab и локальной историей проектов.

  • Git
  • Git Bash
  • Контроль версий
  • GitHub и GitLab
