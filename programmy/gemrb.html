Как установить GemRB в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.gemrb.gemrb
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

GemRB is a portable, open-source implementation of Bioware's Infinity Engine, used in a number of classic computer role playing games such as Baldur's Gate, Icewind Dale and Planescape Torment. The goal of the project is to make the Infinity Engine games available on a wide range of platforms forever, fix or avoid old bugs, add new features and provide a superb platform for mod development. PLEASE NOTE: GemRB does not include game data for any of the supported commercial titles. To play any of the commercial titles, you will need to provide the game data. Please refer to the GemRB documentation for more detail on how to provide it.
