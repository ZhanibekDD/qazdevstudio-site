Что делает Bambu Studio

Bambu Studio — приложение для работы с изображениями и графикой. Разработчик: Bambu Lab. Актуальная версия 2.7.1.62 Public Release распространяется по лицензии AGPL-3.0-only. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.
