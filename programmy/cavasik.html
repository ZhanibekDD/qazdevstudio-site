Как установить Cavasik в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.TheWisker.Cavasik
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Cavasik is an audio visualizer based on CAVA Five normal drawing modes! Two circle drawing modes! Five mirror drawing modes! Four drawing directions! Customizable LibAdwaita interface! Set a single color or up to a 10 color linear gradient for background and foreground! Select different foreground colors for the mirrored images in mirror mode! Set up a color animation that changes the colors gradually in a loop! Configure smoothing, noise reduction and a few other CAVA settings! Change background and foreground colors through a DBus interface! Change background and foreground colors on startup by reading them from a file!
