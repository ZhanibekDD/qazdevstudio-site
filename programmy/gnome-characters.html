Поиск и копирование эмодзи, символов, валют и знаков разных письменностей.

О программе

Characters группирует знаки по категориям и позволяет искать их по названию. Выбранный символ копируется в буфер обмена вместе с вариантами начертания.

Возможности

  • Эмодзи
  • Специальные символы
  • Поиск
  • Копирование

Как установить Characters в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.gnome.Characters
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
