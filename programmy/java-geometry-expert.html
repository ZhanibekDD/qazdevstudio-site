Что делает Java Geometry Expert

Java Geometry Expert — приложение для работы с изображениями и графикой. Разработчик: ADG Foundation. Актуальная версия 0.87 распространяется по лицензии GPL-3.0-or-later. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.
