Оригинальное описание разработчика

About JPEG2PDF JPEG2PDF is a fast and easy-to-use image to PDF converter for Linux. Convert JPG, JPEG, PNG, BMP, GIF, TIFF, SVG, WebP, and other image formats into high-quality PDF documents in just a few clicks. Create single or multi-page PDF files from your photos and images while preserving image quality and page layout. Whether you need to convert scanned documents, photos, screenshots, receipts, or artwork into PDF, JPEG2PDF provides powerful customization options, including page size, margins, orientation, DPI, page numbering, grayscale conversion, and AES-256 PDF encryption. Features Convert JPG, JPEG, PNG, BMP, GIF, TIFF, SVG, WebP, and other image formats to PDF. Batch convert multiple images into a single PDF or create separate PDF files. Automatic image orientation and intelligent page formatting. Adjust page margins and image alignment. Support for standard paper sizes including A4, A3, A5, Letter, Legal, and more. Rotate selected images or PDF pages before exporting. Create grayscale or black-and-white PDF documents. Add automatic page numbers with customizable fonts and styles. Set custom DPI for optimal print and image quality. Protect PDF documents using AES-256 encryption with password security. Fast, lightweight, and privacy-friendly with all processing performed locally.
