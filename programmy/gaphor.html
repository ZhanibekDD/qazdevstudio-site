Как установить Gaphor в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.

Команда для терминалаflatpak install flathub org.gaphor.Gaphor

Оригинальное описание разработчика

Gaphor is a UML, SysML, RAAML, and C4 modeling application. It is designed to be easy to use, while still being powerful. Gaphor implements a fully-compliant UML 2 data model, so it is much more than a picture drawing tool. You can use Gaphor to quickly visualize different aspects of a system as well as create complete, highly complex models. Gaphor provides four modeling languages: UML, SysML, RAAML and C4 and makes them accessible to beginners.
