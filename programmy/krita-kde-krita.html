О программе

Krita — приложение для работы с изображениями и графикой. Разработчик: Krita Foundation. Актуальная версия 5.3.2.1 распространяется по лицензии GPL-3.0-only. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Krita в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.kde.krita
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

This flatpak is community maintained. Please report Flatpak specific bugs that do not occur on the upstream AppImage at https://github.com/flathub/org.kde.krita/issues. Krita is the full-featured digital art studio. It is perfect for sketching and painting, and presents an end–to–end solution for creating digital painting files from scratch by masters. Krita is a great choice for creating concept art, comics, textures for rendering and matte paintings. Krita supports many colorspaces like RGB and CMYK at 8 and 16 bits integer channels, as well as 16 and 32 bits floating point channels. Have fun painting with the advanced brush engines, amazing filters and many handy features that make Krita enormously productive.
