Скачать Tabularis

Настольная SQL-среда для запросов, таблиц, ноутбуков и анализа планов выполнения.

О программе

Tabularis подключается к популярным реляционным базам, Redis и аналитическим системам. В приложении есть SQL-ноутбуки, визуальный EXPLAIN и инструменты для исследования данных.

Возможности

  • SQL-ноутбуки
  • EXPLAIN
  • PostgreSQL
  • Анализ данных
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
