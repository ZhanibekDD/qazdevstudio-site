О программе

Gear Lever добавляет AppImage в меню приложений, хранит их в одном месте и помогает управлять версиями. Поддерживает интеграцию с рабочим столом и обновления совместимых пакетов.

Возможности

  • Управление AppImage
  • Интеграция в меню
  • Обновления
  • Единая библиотека

Как установить Gear Lever в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub it.mijorus.gearlever
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
