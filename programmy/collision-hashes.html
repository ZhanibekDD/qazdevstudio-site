Проверка контрольных сумм файлов перетаскиванием без командной строки.

О программе

Collision вычисляет популярные хэши и сравнивает их с опубликованной контрольной суммой. Так можно убедиться, что загруженный файл не повреждён и не был подменён.

Возможности

  • SHA-256
  • Сравнение хэшей
  • Перетаскивание файлов
  • Несколько алгоритмов

Как установить Collision в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub dev.geopjr.Collision
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
