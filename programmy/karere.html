Оригинальное описание разработчика

Karere brings WhatsApp to your Linux desktop with a native look and feel. It integrates seamlessly with your environment, offering a clean, modern interface that respects your system's theme and workflow. By wrapping WhatsApp Web, it ensures you have access to all the latest features while adding powerful desktop-specific capabilities. Key features include: Native system notifications and tray icon support Persistent login sessions so you don't need to scan the QR code every time Privacy controls and comprehensive spell-checking settings Smooth performance with hardware acceleration Proper clipboard integration for text and images Now built on CEF/Chromium 148. Karere 4.0 replaces the WebKitGTK backend with the Chromium Embedded Framework, bringing full video attachment playback (H.264/AAC), multi-account support with isolated sessions, per-account zoom, and a faster, more compatible rendering engine while keeping the same native GTK4/libadwaita shell.
