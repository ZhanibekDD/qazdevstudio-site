Оригинальное описание разработчика

Boxflat enables you to change your Moza Racing hardware settings with ease as well as adding SDL/Proton detection fixes for any of your devices (pedals, shifters, handbrakes etc.) from other brands. Settings and their values are a 1:1 match with Pit House. This makes it possible to use presets shared by the community. The table of supported settings compared to Pit House can be found on the project website. This project has no official ties to Moza and/or their software. It's 100% independent work based largely on hours of reverse engineering the protocol. Boxflat supports saving/loading presets and automatic per-game application. If a device misses an axis an/or a button, an automatic game detection fix will be applied. No need for other software/SDL hints to make them work. Supported devices: Wheelbases Wheels Pedals Handbrake Sequential shifter H-Pattern shifter Multi-function stalks E-Stop Universal Hub Digital Dash v2 Generic joysticks (only detection fix) Note: The udev rules found in the GitHub repository need to be installed for the application to work properly. Boxflat will remind you of this in case of no rw access to the serial devices.
