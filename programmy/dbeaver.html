Универсальный клиент для PostgreSQL, MySQL, SQLite и других баз данных.

О программе

DBeaver Community позволяет подключаться к разным базам данных, выполнять SQL-запросы, просматривать таблицы, импортировать и экспортировать данные.

Возможности

  • SQL
  • PostgreSQL
  • MySQL
  • SQLite
