Как установить Gitte в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub de.wwwtech.gitte
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Gitte is built around putting commits together with care. Stage or discard your changes line by line, in larger blocks, or a whole file at a time, so every commit holds exactly the work you mean it to and nothing more. It opens straight into your current changes, ready to work. Beyond that, follow how your project's history branches and merges in a visual graph, organize branches and tags, set work aside for later, and sync with the places your code is stored, all in a clean, native interface.
