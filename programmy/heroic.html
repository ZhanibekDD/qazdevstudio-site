Как установить Heroic в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.heroicgameslauncher.hgl
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Heroic is an Open Source Games Launcher. Right now it supports launching games from the Epic Games Store using Legendary, GOG Games using our custom implementation with gogdl and Amazon Games using Nile. Main Features: Have access to your Epic, GOG and Amazon Games in a intuitive User Interface. Add Games outside GOG, Amazon or Epic Games Store native or not. Even Browser apps are supported A Download queue to download multiple games at once. Install and launch your Windows Games using Wine or Proton. Or Launch your Native GOG Games. Cloud Saves support for GOG and Epic Games. Import Games installed through the Epic Store or GOG Galaxy. Verify and Repair corrupted installations or even move your installation to different folders. Integrated Proton/Wine Manager for easy installation of new and updated ones Integrated Winetricks Support for install and uninstall of Games DLCs Access the Epic and GOG store and also Heroic Wiki directly from the App. Check Metacritic, IGCB or OpenCritic score for the game. And many more features Current Limitations on the Flatpak: Due to issues with controller on SteamDeck Gaming Mode Heroic uses Flatpak Runtime 23.08 on stable branch. If you need runtime 24.08 to have HDR support and more please use the beta branch of flathub. Heroic will not find or use Wine and Proton Flatpak versions. At least for now. For now would be better to use the Built-in Wine Manager to download and install Wine and Proton Versions. It should find Proton from the Steam folder for both Steam Flatpak and non-Flatpak if they are on installed on the library inside your $HOME folder Heroic cannot access /usr/bin so it won't be able to find any wine or proton isntalled there for now.
