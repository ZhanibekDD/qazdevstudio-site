Как установить Daphne в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.kymorphia.Daphne
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Daphne Music Player started as a showcase of the D programming language which uses the GTK4 graphics toolkit and the giD GObject Introspection bindings. It has since become a great music player, providing an intuitive interface organized into artists, albums, and songs. A play queue provides a straightforward interface for manipulating playlists and the history keeps a record of played songs. A spectrum visualizer shows audio playback with customizable colors.
