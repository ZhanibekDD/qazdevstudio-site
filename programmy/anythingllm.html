Скачать AnythingLLM

Локальное рабочее пространство для общения с моделями и поиска по своим документам.

О программе

AnythingLLM подключает локальные или облачные языковые модели, индексирует документы и создаёт отдельные рабочие пространства. Подходит для приватного чата, RAG-поиска и AI-агентов.

Возможности

  • Локальные модели
  • Чат с документами
  • RAG
  • AI-агенты
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
