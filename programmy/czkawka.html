Скачать Czkawka

Поиск дубликатов, пустых папок, больших и похожих файлов.

О программе

Czkawka помогает освободить место: ищет одинаковые и похожие файлы, большие объекты, пустые папки и повреждённые элементы без отправки данных в облако.

Возможности

  • Дубликаты
  • Очистка диска
  • Похожие фото
  • Офлайн
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
