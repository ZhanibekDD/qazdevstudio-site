Как установить Materialious в Linux

Оригинальное описание разработчика

Materialious is a client for Invidious and YouTube using material design. It lets you browse and watch videos, manage playlists and visit channels. Features: Use in local mode without relying on a Invidious instance Invidious companion support Invidious API extended integration YouTube.js fallback if Invidious fails loading videos Support for disabling certificate validation for homelab users Sync your watch progress between Invidious sessions Watch sync parties Sponsorblock built-in Return YouTube dislikes built-in DeArrow built-in (With local processing fallback) No ads No tracking Light/Dark themes Custom colour themes Integrates with Invidious subscriptions, watch history and more Live stream support Dash support Chapters Audio only mode Playlists
