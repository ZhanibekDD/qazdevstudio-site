Скачать Arduino IDE

Среда разработки и загрузки программ на платы Arduino и совместимые контроллеры.

⊞ Скачать · Windows 64-bit

О программе

Arduino IDE содержит редактор скетчей, менеджер плат и библиотек, монитор порта и отладку. Помогает собирать прошивки и загружать их на микроконтроллеры через USB.

Возможности

  • Скетчи Arduino
  • Менеджер плат
  • Библиотеки
  • Монитор порта

Как скачать Arduino IDE

  1. Выберите кнопку для своей операционной системы.
  2. Браузер сразу запросит оригинальный файл разработчика.
  3. Проверьте имя файла и завершите установку.
Безопасная загрузка: ссылка и SHA-256 взяты из проверенного манифеста Microsoft WinGet. QazDev передаёт оригинальный файл автора и не изменяет установщик.
