Как установить jamovi в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.jamovi.jamovi
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

jamovi is an advanced, real-time, statisticial spreadsheet, providing a suite of common statistical methods such as descriptives, t-tests, ANOVAs, correlation matrices, proportion tests, contingency tables, and factor analysis. Additional analyses are available from the jamovi library.
