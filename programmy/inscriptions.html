Как установить Inscriptions в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.elly_code.inscriptions
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

A fast, pretty, and ready translation app using DeepL free and paid API Some points of note: Nimble: Paste your DeepL api key (Whichever the plan), and here you go! Thoughtful: Just what you need, out of your way and a click away Comprehensive: No scary angry dialogs - If something goes wrong, explain nicely Lean: Limiting resource usage and internet communications to the minimum Supported languages: All those available via DeepL API! If you like this app please do not hesitate to donate to encourage its development! Libretranslate support is considered, but a heavy time and energy investment, so may or may not happen.
