О программе

Errands организует личные дела по спискам, поддерживает подзадачи, сроки и повторения. Через CalDAV задачи можно синхронизировать с совместимым сервером.

Возможности

  • Списки задач
  • Подзадачи
  • Сроки и повторы
  • CalDAV

Как установить Errands в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.mrvladus.List
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
