О программе

Koodo Reader — приложение для работы с документами и задачами. Разработчик: Troye Guo. Актуальная версия 1.7.4 распространяется по лицензии AGPL-3.0. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Koodo Reader в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.troyeguo.koodo-reader
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
