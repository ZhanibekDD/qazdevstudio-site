Оригинальное описание разработчика

A pixel art logic game: As soon as you pass through a door, a number of other passages close permanently. Can you reach the exit - in all levels? There are 25 levels and one bonus level. This game taking place at a grid, similar to Katomic or Simple Sokoban. Some friends even remind this game of Pushy, although it really has nothing to do with it. The goal of my game is to go to the exit. If you use one door, you can't open a second door with the same number/colour. Every door with a number greater than 21 will shown as questionmark so you don't know what number the door has. Use [L], [-] and [+] to choose a level, [ON] to start with the first level and the arrow keys to move. You can also move by clicking in the direction you want to go. If you move over the border you reach the other side of field. To do this please use the arrow keys/buttons. Good luck! This game is written in JS/HTML/CSS and is using the Tauri framework for making an installable version of the web page of DOORS.
