Оригинальное описание разработчика

jdAppStreamEdit (previously known as jdAppdataEdit) allows you to easily create and edit AppStream (.appdata.xml or .metainfo.xml) files for your Application. Features: Easy to use Full support for the Open Age Rating System (OARS) The AppStream files are fully translatable Releases can be imported from GitHub, GitLab, Gitea, Git Repos and NEWS files You can view a preview in Gnome Software You can use a existing .desktop file as template Supports External Releases Plugins
