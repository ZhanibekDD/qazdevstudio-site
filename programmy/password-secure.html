Оригинальное описание разработчика

Password Secure encrypts the user's accounts and web sites login data, using a master password. Features: state-of-the-art AES-256 symmetric-key encryption offline storage, using portable files automatic backup creation, before updating the stored data secure copying and editing of passwords, without revealing them automatic clipboard clearing on application exit
