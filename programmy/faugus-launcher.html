Как установить Faugus Launcher в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.Faugus.faugus-launcher
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Main Features: Play Windows games using Proton Play Linux native games Run Windows games directly from the .exe file Prefix management Shortcut and Steam shortcut management Integrated tools: Winetricks: A helper tool to easily install dependencies, fonts, DLLs, and tweaks for Wine. Winecfg: Wine's graphical interface to configure Windows versions, libraries, drivers, and integrations. MangoHud: Shows an overlay for monitoring FPS, temperatures, CPU/GPU load and more. Feral GameMode: Tweaks your system to improve performance. Disable Hidraw: May fix controller issues in some games. Additional Application: An additional application to run with the game, like Cheat Engine, Trainers, Mods... Lossless Scaling Frame Generation: Create fake frames to increase the framerate. Proton Manager: Download/Remove GE-Proton and Proton-EM builds. Wine Wayland Driver support (Experimental). HDR Support (Experimental). Known issues with Flatpak: The 'stop' button won't close games. Gamescope doesn't work. It may not use the system theme in some DEs.
