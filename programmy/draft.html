Как установить Draft в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.gitlab.luiggircardoso.Draft
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

You know those text snippets you need to save, that quick idea you want to write down, or a link you need to hold onto but don't want to open a heavy app just for it? This is Draft. Draft is a distraction-free scratchpad tailored for exactly those moments. With Draft, you don't need to worry about creating files or sending links to yourself on messaging apps. Just paste it, and it's safely stored for as long as you need it. Once you're done, clear it out, and it's back to a clean, simple text box! Features: Instant automatic saving - never lose your snippets Distraction-free, single-window UI built for GNOME Word and character counter to keep track of your notes Quick clear button to start fresh instantly
