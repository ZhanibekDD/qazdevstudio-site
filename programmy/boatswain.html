О программе

Boatswain — приложение для работы со звуком и музыкой. Разработчик: Georges Basile Stavracas Neto. Актуальная версия 6.0 распространяется по лицензии GPL-3.0-or-later. Как установить Boatswain в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.feaneron.Boatswain
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Boatswain allows you to control Elgato Stream Deck devices. With Boatswain you will be able to: Organize your actions in pages and profiles Set custom icons to actions Control your music player Play sound effects during your streams Control OBS Studio using Stream Deck (requires the obs-websocket extension) Send network requests Keep track of your gaming score Open files and launch applications
