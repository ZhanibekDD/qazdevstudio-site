О программе

Flatseal показывает доступ приложений к файлам, устройствам, сети и системным службам. Разрешения можно включать, ограничивать и возвращать к исходным значениям без командной строки.

Возможности

  • Права Flatpak
  • Доступ к файлам
  • Сброс настроек
  • Без терминала

Как установить Flatseal в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.github.tchx84.Flatseal
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
