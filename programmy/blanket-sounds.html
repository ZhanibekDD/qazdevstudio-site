О программе

Blanket смешивает несколько окружающих звуков и сохраняет пользовательские наборы. Таймер помогает выключить воспроизведение после работы, медитации или перед сном.

Возможности

  • Фоновые звуки
  • Микшер
  • Свои наборы
  • Таймер

Как установить Blanket в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.rafaelmardojai.Blanket
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
