Оригинальное описание разработчика

Fedinspect is an application for analysing Fediverse servers and user accounts. It provides detailed information about server configurations, capabilities, and user profiles using standard protocols like NodeInfo, WebFinger, and ActivityPub. Features: NodeInfo protocol checks and schema validation Mastodon API v1 and v2 support WebFinger user lookup of ActivityPub actors HTTP debug information
