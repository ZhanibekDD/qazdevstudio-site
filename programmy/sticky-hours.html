Оригинальное описание разработчика

Sticky Hours is an app designed to find common gaps in secondary school schedules. Useful for finding time to speak someone or work on a project. Do note that the app requires that your school uses Zermelo to schedule, and you need access to it. Sticky Hours is an unofficial app using the Zermelo api and not associated with Zermelo. For help with logging in, please take a look at the faq on the website. The app uses GTK for the ui, so you can apply any GTK theme to the app. To do that you will need to allow the flatpak to access the GTK themes folder. The GTK themes folder is ~/.themes for user installed themes, or xdg-config/gtk-3.0 for package installed themes. This value will be referenced as INSERT_GTK_THEMES_FOLDER later on. If you installed the flatpak system-wide, run the following command: sudo flatpak override --filesystem=INSERT_GTK_THEMES_FOLDER If installed Sticky Hours for only one user, run flatpak override --user --filesystem=INSERT_GTK_THEMES_FOLDER
