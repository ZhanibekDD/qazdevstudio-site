О программе

Aurea — приложение для управления файлами и резервными копиями. Разработчик: Cleo Menezes Jr.. Актуальная версия 1.6.1 распространяется по лицензии GPL-3.0-or-later. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Aurea в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.cleomenezesjr.aurea
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Aurea is a simple preview banner made to read metainfo files from Flatpak apps and represent them as they would on Flathub.
