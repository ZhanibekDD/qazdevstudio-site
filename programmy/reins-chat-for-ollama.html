Оригинальное описание разработчика

Reins is a powerful chat client for your self-hosted Ollama AI models. Connect remotely, customize prompts, adjust parameters, and manage multiple conversations with ease. Key Features: Connect to remote Ollama servers Custom system prompts per chat Edit and regenerate responses Send images Fine-tune model parameters (temperature, context size, etc.) for each chat Switch models mid-conversation Create custom models from chats Real-time message streaming Requires a self-hosted Ollama Server.
