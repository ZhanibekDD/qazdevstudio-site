Скачать Flow Launcher

Быстрый запуск программ, поиск файлов, команд и веб-запросов в Windows.

О программе

Flow Launcher открывает приложения, ищет файлы, выполняет команды и поддерживает плагины. Вызывается горячей клавишей и ускоряет повседневную работу в Windows.

Возможности

  • Поиск
  • Запуск программ
  • Плагины
  • Windows

Как скачать Flow Launcher

  1. Выберите кнопку для своей операционной системы.
  2. Браузер сразу запросит оригинальный файл разработчика.
  3. Проверьте имя файла и завершите установку.
Безопасная загрузка: кнопка получает последний релиз через GitHub API. QazDev передаёт оригинальный файл автора и не изменяет установщик.
