О программе

Jan — приложение для работы с изображениями и графикой. Разработчик: Menlo Research Pte. Ltd.. Актуальная версия 0.8.3 распространяется по лицензии Apache-2.0. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Jan в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub ai.jan.Jan
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Jan is an open source alternative to ChatGPT that runs 100% offline on your computer. Features Local AI models: Run LLMs such as Llama, Gemma, Qwen and others on your device Optional cloud access: Connect to services like OpenAI, Anthropic, Gemini and Groq when internet-based models are required Custom assistants: Create tailored assistants for writing, coding, summarizing and more OpenAI-compatible API: Includes a local API server at localhost:1337 for tools expecting the OpenAI format MCP support: Integrates the Model Context Protocol for enhanced workflows and tooling Privacy-aware design: Jan works offline by default. Cloud access is optional and user-controlled Jan is actively maintained by Menlo Research. Feedback, bug reports and feature requests are welcomed through GitHub.
