Скачать MarkEdit

Лёгкий Markdown-редактор для macOS в стиле стандартного TextEdit.

О программе

MarkEdit быстро открывает и редактирует Markdown без перегруженного интерфейса. Подходит для коротких заметок, документации и правок обычных текстовых файлов на Mac.

Возможности

  • Markdown
  • macOS
  • Минимализм
  • Быстрый редактор

Как скачать MarkEdit

  1. Выберите кнопку для своей операционной системы.
  2. Браузер сразу запросит оригинальный файл разработчика.
  3. Проверьте имя файла и завершите установку.
Безопасная загрузка: кнопка получает последний релиз через GitHub API. QazDev передаёт оригинальный файл автора и не изменяет установщик.
