Оригинальное описание разработчика

Cross-platform checksum generation and verification tool with CLI and GTK3 GUI. Features recursive directory hashing, file verification, real-time progress tracking, and support for symbolic links. Supports 11 hash algorithms: CRC32, MD4, MD5, SHA1, SHA256, SHA384, SHA512, SHA3-256, SHA3-384, SHA3-512, and BLAKE3.
