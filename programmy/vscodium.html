О программе

VSCodium предоставляет знакомый редактор кода с вкладками, терминалом, Git и расширениями. Сборка создаётся из открытого исходного кода VS Code и отключает фирменную телеметрию.

Возможности

  • Редактор кода
  • Расширения
  • Встроенный терминал
  • Без телеметрии Microsoft
