Что делает Hedge Mod Manager

Hedge Mod Manager — приложение для игр и развлечений. Разработчик: hedge-dev. Актуальная версия 8.0.0-beta7 распространяется по лицензии MIT. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.
