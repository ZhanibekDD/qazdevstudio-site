Скачать eSearch

Скриншоты, запись экрана, офлайн-OCR, перевод и поиск по изображению.

О программе

eSearch захватывает область экрана и сразу предлагает распознать текст, перевести его или найти изображение. Есть длинные скриншоты, закрепление картинки поверх окон и запись видео.

Возможности

  • Скриншоты
  • OCR
  • Перевод
  • Запись экрана
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
