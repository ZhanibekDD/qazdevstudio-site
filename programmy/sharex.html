Скриншоты, запись экрана, распознавание текста и быстрая обработка изображений.

О программе

ShareX — мощный инструмент для скриншотов и записи экрана. Он умеет захватывать область, прокручиваемую страницу, распознавать текст, добавлять стрелки и скрывать конфиденциальные данные.

Возможности

  • Скриншоты
  • Запись экрана
  • OCR
  • Редактор
Безопасная загрузка: кнопка получает последний релиз через GitHub API и скачивает оригинальный файл автора. QazDev не хранит и не изменяет установщик.
