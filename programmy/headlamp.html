О программе

Headlamp — приложение для настройки и обслуживания Linux. Разработчик: Kinvolk. Актуальная версия 0.43.0 распространяется по лицензии Apache-2.0. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Headlamp в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.kinvolk.Headlamp
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Headlamp is an easy-to-use and extensible Kubernetes web UI. It was created to be a Kubernetes web UI that has the traditional functionality of other web UIs/dashboards available (i.e. to list and view resources) and extra functionality provided by plugins.
