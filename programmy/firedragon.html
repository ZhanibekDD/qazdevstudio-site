Как установить FireDragon в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.garudalinux.firedragon
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

FireDragon is a browser based on the excellent Floorp browser. It was customized to have dr460nized-fitting aestetics as well as many opiniated settings by default. As this browser was originally a Librewolf fork, we are trying to integrate its best patches and tweaks in the new base. The most important features in addition of Floorps own ones can be found below. Searx & Whoogle search engines added, with the possibility to run locally The default search engine is Garuda's Searx instance Dark Reader Sweet theme added Custom, dr460nized branding 🐉 Keeping settings in sync with Librewolfs changes Firefox accounts are enabled using a custom self-hosted sync server (ffsync.garudalinux.org) Faster webpages loading from: Custom Firedragon settings, Inclusion of FastFox tweaks Artwork by @SGS Hidden Navigation buttons instead of being greyed out when they are inactive PBMode Security
