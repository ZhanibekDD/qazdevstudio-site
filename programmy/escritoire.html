Как установить Escritoire в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.

Команда для терминалаflatpak install flathub page.codeberg.dudenix.escritoire
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Escritoire helps you to create standards-compliant letters with ease. Just write your text, select a style and Escritoire will do the rest. You can store your correspondents in an integrated addressbook and use different sender addresses. Currently, Escritoire is limited to DIN 5008 letters. Escritoire uses the power of the Typst typesetting system.
