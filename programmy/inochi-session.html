О программе

Inochi Session — приложение для работы с изображениями и графикой. Разработчик: Luna the Foxgirl. Актуальная версия 0.8.7 распространяется по лицензии BSD-2-Clause. Как установить Inochi Session в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.inochi2d.inochi-session
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Inochi2D is a framework for realtime 2D puppet animation which can be used for VTubing, game development and digital animation. Inochi Session is a tool that lets you use your Inochi2D models for live streaming.
