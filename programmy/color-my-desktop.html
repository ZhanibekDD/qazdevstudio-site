Как установить Color My Desktop в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.schwarzen.colormydesktop
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Color My Desktop is designed to give you full control over your Gnome-shell, KDE Plasma, GTK4 apps, Nautilus, Zen-Browser, and even Vesktop aesthetics. Creates and manages custom color palettes. Generates and applies matching themes using selected color pallete. Supports uniform themes for numerous apps and system UI elements.
