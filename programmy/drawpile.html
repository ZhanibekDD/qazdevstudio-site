О программе

Drawpile — приложение для работы с изображениями и графикой. Разработчик: askmeaboutloom, Calle Laakkonen and contributors. Актуальная версия 2.3.0 распространяется по лицензии GPL-3.0+. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Drawpile в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub net.drawpile.drawpile
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Drawpile lets you draw, sketch, paint and animate together with other people on the same canvas.
