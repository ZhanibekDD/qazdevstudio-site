О программе

Easyflatpak — приложение для работы в интернете и с сетью. Разработчик: Michael Bertocchi. Актуальная версия 4.3.5 распространяется по лицензии LGPL-2.1-only. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Как установить Easyflatpak в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.dupot.easyflatpak
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

It will help you install Flatpak apps in a user-friendly way. We have recipes for some of them to install them even better. For example, for Steam, it asks the user to choose a folder where they store their games before installation. And you can setup this games path in the settings page for all applications which need it (steam,lutris, heroic games launcher, bottles) Bundles are available to install multiple applications in same time You can install your local .flatpak files stored in Downloads directory (application is not allowed to access your other directories) You can downgrade an application version You can click on install button directly on grid list to install directly You can install many applications in parallel Available in many languages: - English - Spanish - French - Italian - Brazilian - Arabic - Romanian
