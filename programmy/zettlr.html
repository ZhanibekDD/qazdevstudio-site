Markdown-редактор для статей, исследований, заметок и больших текстовых проектов.

О программе

Zettlr рассчитан на авторов и исследователей: управляет библиотекой Markdown-файлов, ссылками, цитатами и экспортом через Pandoc. Подходит для подготовки статей и книг без привязки к облаку.

Возможности

  • Markdown
  • Цитаты
  • Pandoc
  • Большие проекты

Как скачать Zettlr

  1. Выберите кнопку для своей операционной системы.
  2. Браузер сразу запросит оригинальный файл разработчика.
  3. Проверьте имя файла и завершите установку.
Безопасная загрузка: кнопка получает последний релиз через GitHub API. QazDev передаёт оригинальный файл автора и не изменяет установщик.
