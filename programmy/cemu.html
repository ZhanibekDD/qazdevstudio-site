Как установить Cemu в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub info.cemu.Cemu
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Cemu is a Nintendo Wii U emulator that is able to run most Wii U games and homebrew in a playable state. Created by Exzap, and written in C/C++. This emulator aims at providing both high-accuracy and performance, and is actively being developed with new features and fixes to increase compatibility, convenience and usability. It was written from scratch and development on the project began roughly early 2015.
