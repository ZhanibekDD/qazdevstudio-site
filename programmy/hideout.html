Оригинальное описание разработчика

Hideout is a minimal and secure desktop application for file encryption and decryption, powered by GnuPG. It provides a simple drag-and-drop interface to protect your sensitive files. Simple UI: Drag and drop files to encrypt or decrypt. Secure: Uses GPG symmetric encryption. Multi-language: Supported in several languages.
