О программе

Botfather — приложение для работы с изображениями и графикой. Разработчик: Botfather. Актуальная версия 6.10.2 распространяется по лицензии MIT. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

Возможности

  • Графика
  • Изображения
  • Открытый код
  • Flatpak

Как установить Botfather в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.botfather.Botfather
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

With Botfather, you can create and run automation bots with ease. Automate your favorite Android, Browser, and Desktop applications using bot scripts. Find scripts online or create your own using Botfathers convenient APIs. Botfather already has image recognition, custom types, and much more built-in.
