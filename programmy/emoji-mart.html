Как установить Emoji Mart в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.vemonet.EmojiMart
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Modern cross-platform popup emoji picker, based on the Emoji Mart web component. Launch the emoji picker with your favorite keyboard shortcut, and select an emoji to paste in the clipboard, or directly in the focused text input on X11. 🍾 Built as a popup: quick invocation through the system custom shortcuts, and disappears when not needed, does not stay as a standalone window, does not run in the background 🔎 Search text box automatically focused and ready to type when invoked ⌨️ Use the keyboard to navigate and select emojis ✒️ On x11 the selected emoji is also automatically pasted to the currently focused text input. 🌍 Complete translation in 22 languages, it will use your system language automatically 🧠 Remembers your frequently used emojis ⚔️ Cross-platform, it can be installed natively on Linux, MacOS, or Windows 🧑‍🚀 Built with Tauri, TypeScript, and Svelte
