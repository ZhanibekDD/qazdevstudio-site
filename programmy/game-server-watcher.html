Оригинальное описание разработчика

Game Server Watcher is a simple application that helps you to monitor the state of your favorite game servers and control remotely the servers of your own. It also has a buddy list and can notify you if a buddy joins any of servers. Features: Server list Buddy list Notifications when your buddy is on a server Multiple query protocols Remote console (Source only)
