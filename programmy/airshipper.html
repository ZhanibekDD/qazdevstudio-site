Как установить Airshipper в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub net.veloren.airshipper
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Airshipper is the official launcher for Veloren, the online voxel-based RPG. Veloren is a multiplayer open world, voxel-based RPG written in Rust. It is inspired by games such as Cube World, Minecraft, Dwarf Fortress and Breath of the Wild. Veloren's development mainly happens on the official Discord server (https://discord.gg/kjwJwjK). New contributors are always welcome!
