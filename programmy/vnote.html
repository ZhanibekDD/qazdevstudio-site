Быстрый нативный редактор Markdown с деревом папок и удобной навигацией.

О программе

VNote предназначен для технических заметок и больших коллекций Markdown-файлов. Поддерживает вкладки, поиск, диаграммы, режим чтения и работу с обычными папками.

Возможности

  • Markdown
  • Быстрый поиск
  • Диаграммы
  • Локальные папки
Безопасная загрузка: кнопка получает последний релиз через GitHub API. QazDev загружает оригинальный файл автора и не изменяет установщик.
