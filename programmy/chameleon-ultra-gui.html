Что делает Chameleon Ultra GUI

Chameleon Ultra GUI — приложение для управления файлами и резервными копиями. Разработчик: GameTec-live. Актуальная версия 1.3 распространяется по лицензии GPL-3.0. Карточка сформирована по проверенным данным Flathub AppStream, а кнопка скачивает официальный Flatpak-профиль без рекламных загрузчиков.

  • Файлы
  • Резервные копии
  • Открытый код
  • Flatpak
