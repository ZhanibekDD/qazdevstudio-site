Оригинальное описание разработчика

Application written in C++ / Qt that allows you to translate and speak text using Mozhi. Features: Multiple translation engines provided by Mozhi (some instances can disable specific engines)* Translate and speak text from screen or selection Highly customizable shortcuts Command-line interface with rich options D-Bus API Available for Linux and Windows *While Mozhi acts as a proxy to protect your privacy, the third-party services it uses may store and analyze the text you send.
