Спокойный Markdown-редактор с предпросмотром и режимом без отвлечений.

◉ Скачать · Linux · Flatpak

О программе

Apostrophe помогает сосредоточиться на тексте, подсвечивает разметку и показывает результат рядом или в отдельном окне. Документ можно экспортировать в HTML, PDF и другие форматы.

Возможности

  • Markdown
  • Предпросмотр
  • Режим фокуса
  • Экспорт документов

Как установить Apostrophe в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.gnome.gitlab.somas.Apostrophe
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
