Как установить ImHex в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub net.werwolv.ImHex
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

ImHex is a modern Hex Editor for Reverse Engineers, Developers, Malware Analysists and Hackers who value their retinas when working at 3 AM once again. Features: Featureful hex view Custom C++-like pattern language for parsing and highlighting a file's content Data importing and exporting Data inspector allowing interpretation of data as many different types Huge file support with fast and efficient loading Strings search File hashing support Disassembler supporting many different architectures: ARM, x86, PowerPC, MIPS, and more Bookmarks Data analyzer Helpful tools such as an Itanium and MSVC demangler, ASCII table, Regex replacer, mathematical expression evaluator (calculator), hexadecimal color picker and many more Doesn't burn out your retinas when used in late-night sessions
