О программе

KleverNotes хранит обычные Markdown-файлы, организует их по папкам и показывает форматированный результат. Поддерживает задачи, вложения, подсветку кода и внутренние ссылки.

Возможности

  • Markdown
  • Папки и поиск
  • Задачи
  • Подсветка кода
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev загружает оригинальный файл автора и не изменяет установщик.
