Оригинальное описание разработчика

Fracture windows then resize, modify, and use shaders with the fractured selection. This application creates fractured views of other applications and desktops. A fractured view is just a mirrored view of a region cut (or cropped) from the original application. After a fractured view is created, it provides the ability to modify it by resizing, scaling, adding transparency, removing colors ranges, adding colors, and by using shaders on it. This release is an early version, if there are issues with it they can be reported with this this forum (https://programming.dev/c/fracture) or by posting issues on the GitHub repository. Note: This application provides support to launch with the active window using a keyboard shortcut on Gnome. On other Desktop Environments, a portal is used instead of the active window. Launching on the active window in Gnome is not a requirement and can be avoided by closing the installer window. If the installer window is closed, it will fallback to using a portal.
