Как установить Fan Control в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.wiiznokes.fan-control
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

You can add items with the buttons on the right of the app. To save a configuration, write a name in the "Configuration name" field, and click on the +. To modify the value of a fan, you must select it in a Control item (the left column), select a Behavior, and activate the swtich. Display sensors data on real time Control fans based on custom behaviors Save configuration Note: After installation, you will need to add the necessary udev rule to your system for this to work. See the GitHub page for more details.
