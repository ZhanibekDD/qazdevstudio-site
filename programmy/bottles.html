О программе

Bottles упрощает работу с Wine: создаёт изолированные окружения, устанавливает компоненты и предлагает готовые настройки для программ и игр. Каждую «бутылку» можно резервировать и настраивать отдельно.

Возможности

  • Окружения Wine
  • Установщики программ
  • Отдельные настройки
  • Резервные копии

Как установить Bottles в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub com.usebottles.bottles
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
