Скачать Secrets

Менеджер паролей для локальных баз KeePass с удобным поиском.

◉ Скачать · Linux · Flatpak

О программе

Secrets открывает и создаёт зашифрованные базы KeePass, хранит логины, заметки и вложения. Есть генератор паролей, поиск, автозаполнение и блокировка базы по таймеру.

Возможности

  • Базы KeePass
  • Генератор паролей
  • Вложения
  • Автоблокировка

Как установить Secrets в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub org.gnome.World.Secrets
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
