Как установить Dragengine Launcher в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub ch.dragondreams.delauncher
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Supports running games and applications based on the Drag[en]gine Game Engine distributed as DELGA files. DELGA files can be run directly by clicking them. Launcher can be used to create and modify game profiles for example to fine tune performance. In general creating profiles is not required.
