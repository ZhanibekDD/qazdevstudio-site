Оригинальное описание разработчика

Lifeograph combines powerful features with a clean and thoughtfully designed interface. Your data stays on your device, and built-in encryption keeps privacy at the core. With WYSIWYG editing, your entries always appear in their final form. Integrated data extraction tools transform your journal entries into dynamic tables and charts. Main features of Lifeograph: Completely local workflow: all data is owned solely by the user Encrypted (with AES256) and unencrypted diaries Powerful and intuitive parametric tagging system Todo management system WYSIWYG rich text formatting (i.e. no separate edit & preview modes) Image thumbnails, tables, and charts in entries Extensibility via Python with support for editing and running scripts from within the program Text searching and replacing with Regex support Advanced filtering of entries Integrated map for travel notes and route planning Live tables that are created on the fly based on the user defined rules which can also be pasted into spread-sheet programs Live statistical charts that are created from the values in the tables Themes in text editor, including background images Favorite entries Spell checking Links between entries and to URIs Automatically created back-links to entries referring to the current entry Printing individual entries or whole diaries Automatically logs out when not used for some time (to protect encrypted diaries) Multiple automatic backups to prevent data loss
