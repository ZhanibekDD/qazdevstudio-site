Оригинальное описание разработчика

Munquet is a lightweight desktop tool for converting and preparing tabular data files with ease. Transform structured data into the efficient Apache Parquet format, reduce file size, merge datasets, and validate column structures — all through a simple graphical interface. Key features: Convert CSV/TSV files to Parquet Merge multiple datasets into one Validate and rename column headers safely Prevent inconsistent or mismatched data Batch processing with progress feedback Works fully offline
