Скачать LocalSend

Передача файлов между компьютером и телефоном по локальной сети.

О программе

LocalSend передаёт файлы напрямую между устройствами в одной сети без облака и регистрации. Работает на компьютерах и мобильных устройствах.

Возможности

  • Передача файлов
  • Без облака
  • Локальная сеть
  • Кроссплатформенность
Безопасная загрузка: кнопка получает последний релиз через GitHub API. QazDev загружает оригинальный файл автора и не изменяет установщик.
