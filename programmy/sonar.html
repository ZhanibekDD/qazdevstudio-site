Как установить Sonar в Linux

  1. Нажмите кнопку «Скачать · Linux · Flatpak».
  2. Откройте загруженный .flatpakref в центре приложений.
  3. Подтвердите установку из официального Flathub.
Команда для терминалаflatpak install flathub io.github.tobagin.sonar
Безопасная загрузка: кнопка скачивает официальный .flatpakref из подписанного репозитория Flathub. QazDev передаёт оригинальный файл автора и не изменяет установщик.
Оригинальное описание разработчика

Sonar is a native tool for debugging webhooks. It captures incoming requests and lets you inspect headers, body content, and query parameters in real-time. Core Features: Instant public URLs via ngrok integration for webhook testing Real-time capture of incoming webhook requests as they arrive Detailed inspection of headers, body content, query parameters, and metadata Quick copy functionality including JSON, cURL, and HTTP formats Clean Libadwaita interface that integrates perfectly with GNOME Fast and lightweight native application with minimal resource usage Advanced Features: Request bookmarking and starring for quick access Request replay to resend webhooks to custom URLs Side-by-side request comparison to spot differences Request templates for saving and reusing webhook patterns Automatic webhook forwarding to multiple URLs Advanced filtering by method, content-type, time range, and search Persistent history with JSON storage
