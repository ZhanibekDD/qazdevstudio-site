Оригинальное описание разработчика

A very intuitive and easy to use 2D chemical structure drawing tool. You can draw molecules and reactions, mechanisms, generate SMILES, save drawings as PNG or SVG. Or you can calculate various properties of molecules. Features : Supports most popular file formats Supports modern file formats like Marvin MRV, Chemdraw CDXML Export to PNG, SVG, and Editable SVG Many bond types including wavy bond, Cis/Trans, Bold double, Any Bond etc Aromaticity detection and add delocalization ring Search and load structure from PubChem Reagent bottle label printing tool
