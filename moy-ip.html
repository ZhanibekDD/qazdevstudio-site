Частые вопросы
Что такое IP-адрес? +
IP-адрес — уникальный числовой идентификатор вашего устройства в интернете, присваиваемый провайдером. По нему можно определить страну, город и провайдера, но не точный домашний адрес.
Почему город определяется неточно? +
Геолокация по IP приблизительная. Провайдер может зарегистрировать IP-блок в одном городе, а обслуживать другой. При мобильном интернете (4G/5G) погрешность выше — трафик проходит через городские узлы сети.
VPN скрывает мой реальный IP? +
Да — VPN заменяет ваш IP на адрес сервера. Сайты видят IP VPN, а не провайдера. Однако некоторые браузеры могут раскрыть реальный IP через WebRTC даже при включённом VPN (утечка WebRTC). Строка "VPN / Прокси" выше показывает, детектируется ли VPN.
Что такое Privacy Score? +
Это наша условная оценка анонимности от 0 до 100. Учитывается: VPN/прокси (-20), Do Not Track (+10), блокировка cookies (-15), тип соединения и другие сигналы. Чем выше — тем меньше данных о вас видят сайты.
Может ли сайт узнать мой точный адрес? +
Нет. По IP можно определить только примерный город и провайдера. Точный адрес (улица, квартира) доступен только провайдеру по официальному запросу правоохранительных органов.
